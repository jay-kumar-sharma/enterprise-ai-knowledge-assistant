# Contributing Guide

Thank you for your interest in contributing to the Enterprise AI
Knowledge Base & Customer Support Assistant.

This project follows a structured development workflow to keep the
codebase maintainable, testable, and easy to understand.

## Development Workflow

Follow these steps when implementing a feature:

1. Create or select the relevant GitHub issue.
2. Create a feature branch.
3. Implement the feature.
4. Add or update tests.
5. Update relevant documentation.
6. Review the changes locally.
7. Commit using a meaningful commit message.
8. Push the feature branch.
9. Open a Pull Request.
10. Review and merge the Pull Request.
